# SSI Survey Hub for Brokers

[**Mở bản demo trực tiếp**](https://manhtuantandinh-cpu.github.io/SSI-Survey-Hub-for-brokers/)

Công cụ hỗ trợ môi giới thiết kế khảo sát khách hàng: hướng dẫn quy trình, thư viện mẫu câu hỏi, trình tạo form và xem trước khảo sát. Bản công khai là demo portfolio; dữ liệu form chỉ lưu trong trình duyệt của người xem, không kết nối hệ thống nội bộ SSI hay dữ liệu khách hàng thật.
